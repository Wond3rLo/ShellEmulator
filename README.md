# Эмулятор командной оболочки

## Описание проекта

Программа представляет собой эмулятор командной оболочки с графическим интерфейсом, реализованный на Python с использованием Tkinter.

Эмулятор работает с виртуальной файловой системой, структура которой загружается из CSV-файла. Команды выполняются над виртуальной файловой системой, а результаты выполнения записываются в XML-журнал.

## Реализованные команды

| Команда | Описание |
|---|---|
| `ls` | Вывод содержимого виртуального каталога |
| `cd` | Изменение текущего виртуального каталога |
| `echo` | Вывод текста |
| `tac` | Вывод содержимого файла в обратном порядке строк |
| `find` | Поиск файлов и каталогов по имени |
| `rm` | Удаление файлов из виртуальной файловой системы |
| `rmdir` | Удаление пустых виртуальных каталогов |
| `vfs-save` | Сохранение виртуальной файловой системы в CSV-файл |
| `vfs-init` | Инициализация виртуальной файловой системы |
| `exit` | Завершение работы программы |

## Требования

- Python 3.11 или новее.
- Tkinter.

## Структура проекта

- `run.bat` — скрипт запуска.
- `main.py` — основной код программы.
- `config.toml` — параметры конфигурации.
- `virtual_fs.csv` — данные виртуальной файловой системы.
- `startup.txt` — стартовый скрипт с командами для проверки работы программы.
- `shell_log.xml` — XML-журнал выполнения команд, создаваемый программой.

## Настройка

В файле `config.toml` задаются пути к виртуальной файловой системе, журналу и стартовому скрипту:

```toml
vfs_path = "src/virtual_fs.csv"
log_path = "shell_log.xml"
script_path = "src/startup.txt"
```

Параметры командной строки могут переопределять значения из конфигурационного файла.

Поддерживаются параметры:

- `--vfs` — путь к CSV-файлу виртуальной файловой системы.
- `--log` — путь к XML-журналу.
- `--script` — путь к стартовому скрипту.
- `--config` — путь к TOML-файлу конфигурации.

## Запуск

В Windows запустите `run.bat` из корневой папки проекта.

Либо выполните команду:

```bash
python src\main.py
```

Для пользовательского запуска:

```bash
python main.py --vfs virtual_fs.csv --log shell_log.xml --script startup.txt --config config.toml
```

## Особенности работы

- Изменения виртуальной файловой системы хранятся в памяти до вызова команды сохранения.
- Команда `rm` предназначена для удаления файлов.
- Команда `rmdir` удаляет только пустые каталоги.
- Корневой каталог нельзя удалить.
- Ошибки выполнения команд отображаются в графическом интерфейсе и записываются в XML-журнал.
- При выполнении стартового скрипта программа прекращает его обработку после первой ошибки.
